## 🔥 UPGRADE 1 — SMART DISPATCH v2 (WEIGHTED OPTIMIZATION)

**Owner:** Member 3 (Dispatch) + Member 1 (Graph)

### 🎯 Objective

Instead of assigning the **nearest rider only**, compute a **weighted score** to choose the **best rider**.

### 📌 New Dispatch Formula

```text
score = (α × distance)
      + (β × jobsCompleted)
      − (γ × idleTime)
```

Suggested weights:

```java
α = 1.0   // distance importance
β = 2.0   // workload balancing
γ = 0.5   // fairness (idle riders preferred)
```

---

### 🧩 CODE TASKS

#### 1️⃣ Rider.java — Add fields

```java
private int jobsCompleted;
private long lastCompletedTime;
```

Initialize in constructor:

```java
this.jobsCompleted = 0;
this.lastCompletedTime = System.currentTimeMillis();
```

Add methods:

```java
public int getJobsCompleted() { return jobsCompleted; }

public long getIdleTime() {
    return System.currentTimeMillis() - lastCompletedTime;
}

public void completeJob(double distance) {
    jobsCompleted++;
    lastCompletedTime = System.currentTimeMillis();
}
```

---

#### 2️⃣ DispatchSystem.java — Modify assignOrder()

Replace:

```java
first available rider
```

With:

```java
Rider bestRider = null;
double bestScore = Double.MAX_VALUE;

for (Rider rider : riderList) {
    if (rider.getStatus() != RiderStatus.AVAILABLE) continue;

    double distance = map.getDistance(
        rider.getCurrentLocation(),
        order.getPickupLocation()
    );

    if (distance < 0) continue;

    double score = (1.0 * distance)
                 + (2.0 * rider.getJobsCompleted())
                 - (0.5 * rider.getIdleTime() / 1000);

    if (score < bestScore) {
        bestScore = score;
        bestRider = rider;
    }
}
```

Then assign using `bestRider`.
